# Application Skeptic (Driver-Planned Phase)

This phase independently reviews producer-authored `SAFE`, `NO_FINDING`, and
`NOT_APPLICABLE` methodology outcomes. The deterministic driver owns the exact
input union, shard plan, assessor identities, JSON schema, reconciliation, and
candidate delivery. A model may assess only the work items in its assigned
driver-rendered shard.

The assessor must distinguish whether the cited methodology operator was
actually applied from whether its semantic result is negative. A supported
negative requires the exact in-scope evidence requested by the shard. Missing,
irrelevant, circular, producer-self-authored, or externally assumed evidence
cannot close the item. Disagreement is additive and enters normal independent
verification; it is not proof and cannot delete, merge, downgrade, or certify
a finding.

If this standalone phase body is reached without a driver-owned work plan and
per-shard output contract, record configuration debt and stop. Do not invent a
queue, scan unrelated artifacts, or write phase-level authority files.
